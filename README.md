# TORO_DiscordBot-Java

TORO サーバー用の Discord ボット (Java) の作業の一覧は、[TORO-Server のプロジェクト](https://github.com/orgs/TORO-Server/projects/2) にあります。

時報と TPS (サーバーの処理の速さ) のログ出力は、[TORO-Core](https://github.com/TORO-Server/TORO-Core) の clock と tps-log のモジュールにまとまっています。
